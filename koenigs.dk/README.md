# Original WeeCade Files

This directory contains the original WeeCade design files by Rasmus Kønig Sørensen.

These files are retained here as reference material for the Parametric WeeCade
project.

The files in this directory are not original work by the Parametric WeeCade
project.

Original source:
http://www.koenigs.dk/

The parametric CAD model being developed in this repository is a separate
development based on the original WeeCade design.
