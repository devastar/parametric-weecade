# Parametric Weecade

An open-source, fully parametric arcade cabinet design for Fusion 360.

The goal of this project is to create a flexible arcade cabinet that can be configured for different:

* Cabinet dimensions
* Monitor sizes and positions
* Control-panel layouts
* Number of players
* Button layouts
* Joystick positions
* Panel thicknesses
* Construction methods

The design is intended to be suitable for CNC fabrication from sheet material while remaining practical for hand fabrication.

## Design goals

* Fully parametric Fusion 360 model
* CNC-friendly construction
* Configurable monitor mounting
* Configurable control-panel layouts
* Support for different sheet thicknesses
* Minimal material waste
* Easy assembly
* Clear fabrication drawings
* Exportable DXF/CNC files
* Open-source and community-friendly

## Project status

**Development**

The cabinet geometry and parametric system are currently being developed.

## Default configuration

The initial reference configuration will be:

* Width: 600 mm
* Height: 750 mm
* Maximum depth: 500 mm
* Material thickness: 18 mm
* Monitor: 24-inch class
* Controls: 2-player

These are starting parameters only. The final design is intended to be configurable.
